# NEVROA — Global Industrial Supply

Official website source for **NEVROA Bilişim Teknolojileri Sanayi ve Ticaret Limited Şirketi**.

Domain: https://nevroagroup.com

## Website
- Responsive static HTML, CSS, JavaScript
- Turkish and English interface
- Corporate identity: Navy #081B2C, Steel #153A5F, Copper #C8894B
- Industrial sourcing sectors: metals, ferroalloys, minerals, carbon, machinery and international trade
- Vector brand logo and favicon
- Accessible navigation and basic SEO metadata

## cPanel deployment
Upload the contents of this repository (not its parent folder) to your domain's document root, usually `public_html`. Enable a valid origin SSL certificate and then choose Cloudflare **Full (strict)**. Verify the domain's nameservers are active and the DNS A record resolves to the intended cPanel host.

## Before launch
Contact addresses are placeholders until company confirms them. The inquiry form deliberately opens an email draft; it does not submit to a backend. Replace this behavior with a protected contact endpoint, anti-spam and privacy disclosure before treating inquiries as live leads. Visuals are generic externally hosted industrial images, not company facilities. Confirm all formal company data, licensing, cookies/privacy and imagery rights before production release.
